1. 형변환
    1-1. 어떤 자료형의 값을 다른 자료형의 값으로 변환하는 것을 의미합니다.
    1-2. 암시적 형변환은 컴파일러가 자동으로 수행하는 형변환
    1-3. 명시적 형변환은 프로그래머가 직접 요청하는 형변환


2. 암시적 형변환(Implicit Type Conversion)
    2-1. 컴파일러가 C++ 언어 규칙에 따라 자동으로 자료형을 변환하는 것입니다.

    2-2. int a = 10; double b = a;
        => 컴파일러가 int a의 값을 double 값으로 자동 변환합니다.
        => cout -> 10.0
        
    2-3. double c = 3.14; int d = c;
        => 이 때 d는 3이 들어갑니다.
        => double -> int 소수 부분이 버려집니다. 
        => 정보를 잃어버릴 수 있는 형변환을 축소 변환(Narrowing Conversion)이라고 합니다.
    
    2-4. 서로 다른 자료형 사이의 산술 연산
        => int a = 10;
        => double b = 3.5;
        => auto result = a + b;
        => 일반적으로 더 큰 자료형인 double 형태로 값이 나옵니다. -> 13.5


3. 명시적 형변환
    3-1. 프로그래머가 직접 특정 자료형으로 변환하도록 요청하는 것입니다.

    3-2. c 언어 명시적 형변환
        => double a = 3.14;
        => int b = (int)a; -> b는 3

    3-3. C++ 명시적 형변환
        1. static_cast
            => static_cast<변환할_자료형>(표현식)
            => double a = 3.14;
            => int b = static_cast<int>(a);
            => a -> 3
        2. int a = int(변수)
            => c와는 다르게 자료형()를 통해 괄호의 변수의 타입을 변경할 수 있습니다.
