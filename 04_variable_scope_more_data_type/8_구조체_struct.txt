1. C++ 구조체
    => 서로 다른 타입들을 묶어서 하나의 자료형으로 사용하는 문법입니다.


2. C 구조체와 차이점-1
    2-1. struct Person {
            int age;
            float height;
        };
        int main() {
            Person p1 = { 20, 175.5f };

            std::cout << p1.age;
        }
    2-2. 2-1 main에 struct를 쓰지 않아도 Person을 바로 자료형으로 사용할 수 있습니다.


3. C 구조체와 차이점-2
    3-1. C언어에서는 일반적인 구조체 내부에 멤버 함수를 직접 정의할 수 없습니다.
        => 구조체 외부에 함수를 정의하고 함수, 함수 포인터를 사용합니다.
    3-2. C++은 구조체 내부에 함수를 정의할 수 있습니다.
        => 이를 멤버 함수라고 합니다.
        => 멤버 함수가 호출된 객체에 대한 정보를 가지고 있습니다.
        => 그래서 멤버 함수가 멤버 변수를 사용하면 그 객체 정보를 가지고 연산합니다.


4. C 구조체와 차이점-3
    4-1. C++11부터는 구조체를 정의할 때 멤버에 기본값을 지정할 수 있습니다.
    4-2. struct Person {
            int age = 20;
            float height = 175.5f;
        };
    4-3. 초기화를 하면 초기값을 따라가고 그렇지 않고 사용한 경우 default 값을 사용합니다.
