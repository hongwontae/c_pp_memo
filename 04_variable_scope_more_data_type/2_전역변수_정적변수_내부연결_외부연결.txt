** 선언은 header / 정의는 실제 cpp 파일 **
** 컴파일 header에 영향 / 링킹은 연결에 영향 **

1. 전역 변수
    1-1. 함수 외부에서 선언한 변수를 전역 변수라고 합니다. -> 일반적으로 모든 곳에서 접근 가능
    1-2. 전역 네임스페이스는 전역 영역입니다.
        => c++에서 좀 더 정확하게 구분하기 위해 전역 네임스페이스라는 용어를 사용합니다.
    1-3. 지역 scope에서 :: value_name을 사용하면 전역에 접근할 수 있습니다.


2. 정적 변수 (static)
    2-1. 전역 정적 변수
        => 전역 변수지만 다른 파일에서 접근할 수 없습니다.
    2-2. 정적 변수
        => 함수 내부에서 선언된 정적 변수입니다.
        => 함수 내부에서만 접근이 가능하고 생명주기가 전역입니다.
        

3. extern 키워드
    3-1. extern은 변수나 함수가 외부 연결을 갖도록 관여합니다.
    3-2. 전역에서 int a = 10; extern int a = 10; -> 다른게 없습니다.
        => int a = 10;은 기본적으로 외부 연결을 가집니다.
    3-3. const 키워드를 가진 변수는 기본적으로 내부 연결입니다. 
        => 외부로 연결하려면 extern 키워드가 필요합니다.


4. 컴파일 시점과 링킹 시점에 따른 해석
    4-1. header 파일을 include 하는 것은 컴파일 시점에 필요합니다.
    4-2. 연결을 하는 것은 링킹 시점에 필요합니다.


5. 서로 다른 파일 a.c, b.c가 존재할 떄
    a에 전역 변수로 int a = 10; b에 extern int a;가 존재할 떄 두 파일을 링킹하면 b는 a의 int를 사용할 수 있습니다.


6. 5처럼 가동하는데 header 파일이 필요한 이유는 중복된 선언을 피하려고 하는 것입니다.


7. 일반적으로 함수는 extern int function () {} 처럼 extern이 숨겨져 있습니다.


8. 같은 이름으로 여러 번 선언 가능 / 단, 정의는 한 번입니다.
    => header에 extern int a;
    => a.c에 extern int a = 10; | int a = 10; -> 둘 다 맞습니다. 둘 다 선언
