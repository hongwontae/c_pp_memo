1. char type
    1-1. 문자형이자 정수형인 특수한 타입입니다.
        => 홑 따옴표 문자나 1bye 내의 숫자를 저장합니다.
    1-2. cout에서 문자로 표현됩니다.
    1-3. char 타입은 연산이 가능합니다. -> ASCII 코드 숫자가 피연산자가 되며 계산의 대상이 될 수 있습니다.


2. cpp 캐스팅
    2-1. 기존의 c의 타입 변환은 (char) b; 형식이었습니다.
    2-2. cpp에서는 형식 변환을 할 떄 char(b); 해당 문법을 허용합니다.
    2-3. byte 범위내에 변환은 메모리 상 값을 변경하지 않습니다.
