1. boolean 자료형
    1-1. 두 가지 값만 갖습니다. true(1) / false(0)


2. 부정 연산자
    2-1. ! 연산자를 통해 true -> false / false -> true로 바꿉니다.


3. && 연산자
    => 오른쪽 피연산자와 왼쪽 피연산자 true여야 true를 반환합니다.


4. || 연산자
    => 오른쪽 피연산자와 왼쪽 피연산자 둘 중 하나만 true -> true를 반환합니다.


5. if문은 ()가 true를 반환해야 본문을 실행하는 구문입니다.
6. if else -> if문이 false면 else를 실행합니다.
7. if else if.. -> if 문이 false면 else if을 확인합니다.
