1. 정수형
    1-1. char는 문자형이자 정수형입니다.
        => 1byte 데이터 크기를 가지고 있습니다.

    1-2. short
        => 2byte 정수형입니다.
    
    1-3. int
        => 4byte 정수형입니다.
    
    1-4. long
        => 4byte || 8byte 정수형입니다.
        => windows에서 4byte이지만 linux에서는 8byte입니다.
    
    1-5. long long
        => 8byte 정수형입니다.
    
    1-6. sizeof(short) <= sizeof(int) <= sizeof(long) <= sizeof(long long)
        => c++은 정수형의 관계를 위처럼 보장합니다.
    
    1-7. 정수형 데이터 타입에서 signed 타입은 가장 앞에 있는 비트로 음수인지, 양수인지 표현합니다.
        => 앞 비트가 1이면 음수입니다.


2. 정수형 오버플로우
    2-1. short는 2byte -> 16bit의 크기의 데이터를 표현할 수 있습니다.
    2-2. signed short -32768 ~ 32767 까지 표현 가능합니다. | unsigned short 0 ~ 65535 까지 표현 가능합니다.
    2-3. 이 떄 부호 없는 정수인 unsigned short의 최대값인 65535 + 1
        => 16bit가 1인 상태에서 1을 더해서 0이되고 비트 올림 수는 저장할 공간이 없어 포함하지 않습니다.
        => 결과적으로 0이 됩니다.
    2-4. 부호 있는 정수인 signed short의 최대값인 32767+1
        => 부호 있는 정수는 가장 앞 비트는 음수, 양수를 결정짓는 비트입니다.
        => 최대값에서 +1 -> 가장 앞에 있는 비트만 1이 되고 나머지는 0이 됩니다.
        => 이 떄 앞에 비트만 1이라면 가장 최소값이 나타나는 특징 떄문에 -32768이 반환됩니다.
