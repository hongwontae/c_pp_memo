1. 문자 타입
    1-1. char a = 'H';
    1-2. 문자 타입, 온따옴표를 사용하고 하나의 문자를 저장합니다.
    1-3. char는 1byte 저장 공간을 가집니다.
    1-4. 문자를 숫자로 바꾸고 숫자를 이진수로 변환하고 1byte 공간에 저장합니다.
    1-5. char16_t / char32_t -> 다양한 문자를 표현하기 위해 더 넓은 저장공간이 허용된 문자 타입입니다.
    1-6. c/c++에서 char, signed char, unsigned char는 모두 문자 타입이면서 정수 타입입니다.
        => std::cout << a << '\n';
        => a가 char, signed, unsigned라면 a가 그대로 출력됩니다.
        => char 데이터가 계산에 참가한다면 int로 승격해서 계산할 수 있습니다.


2. 정수 타입
    2-1. int a = 10;
    2-2. 정수 타입, 숫자를 저장합니다.
    2-3. int는 4byte 저장 공간을 가집니다.
    2-4. unsigned int는 양의 정수와 0을 포함합니다. / signed는 음수, 0, 양의 정수를 포함합니다.
    2-5. 다양한 정수 타입
        1. signed short int
        2. signed int
        3. signed long int
        4. signed long long int
            => c++에서는 signed를 생략해서 사용할 수 있습니다. -> signed가 기본값
            => 다만 char != signed char가 아닙니다.
        5. unsigned short int 
        6. unsigned int
        7. unsigned long int
        8. unsigned long long int
            => short, long, long long을 사용할 떄 뒤에 int을 생략할 수 있습니다.
            => signed, unsigned 모두 해당됩니다.


3. 부동 소수점 타입 -> 실수를 저장할 때 사용하는 데이터 타입입니다.
    3-1. float
        => 4byte를 사용합니다.
        => 5자리만 표현합니다.
        => 부동 소수점 리터럴에 f를 붙이면 float 타입이 됩니다.
    
    3-2. double
        => 8byte를 사용합니다.
        => 부동 소수점 리터럴은 기본적으로 double 타입입니다.
        => float a = 3.121592.. -> 3.121..은 double 형식인데 float 자료형 변수에 초기화될 때 float이 됩니다.
    
    3-3. long double
        => 8, 12, 16 byte 중 하나를 사용합니다.


4. bool 타입
    4-1. true와 false의 논리값을 저장하는 데이터 타입입니다.
    4-2. 정수 타입으로 변환이 가능합니다. 
        => 0 -> false / !0 -> true
    4-3. 논리식의 값으로 사용됩니다.
    4-4. cout에 bool 변수를 넣으면 정수로 출력됩니다.


5. void 타입
    => 값이 없다는 사실을 표현하는 데이터 타입입니다.
    => 함수의 반환 타입, 포인터에서 주로 사용됩니다.


6. sizeof()
    6-1. 값이나 변수나 타입을 인자로 받습니다.
    6-2. 인자의 타입을 기준으로 데이터 크기를 반환합니다.
    6-3. 반환형은 size_t 정수형입니다. -> unsigned 정수형
