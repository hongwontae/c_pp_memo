1. C++에서 랜덤 숫자를 생성하는 방법은 크게 두 가지입니다.
    1-1. rand() — C언어부터 사용되던 전통적인 방법
    1-2. <random> 라이브러리 — C++11부터 도입된 현대적인 방법


2. C rand() 함수
    2-1. c++에서 cstdlib 헤더에 정의된 rand()를 사용합니다.
        => 0부터 RAND_MAX 사이의 정수를 반환합니다.
        => 프로그램을 다시 실행하면 동일한 난수 순서가 나올 수 있습니다.
    
    2-2. 의사 난수
        => 컴퓨터는 특정 알고리즘을 사용해서 무작위처럼 보이는 숫자들을 생성할 수 있습니다.
        => 이러한 숫자는 완전한 무작위가 아니라, 내부 상태에 의해 결정되는 숫자입니다.
        => 이를 의사 난수라고 합니다.
        => 의사 난수 생성기는 초기 상태를 결정하는 값인 **시드(Seed)**를 사용합니다.
        => 같은 시드를 사용하면 같은 숫자가 나옵니다.
    
    2-3. srand()로 시드를 지속적으로 바꿔주기
        => std::srand(static_cast<unsigned int>(std::time(nullptr)));
        => std :: srand() -> 난수 생성기의 시드를 설정합니다.
        => std :: time(nullptr) -> 현재 시간을 초 단위로 반환합니다.
        => 현재 시간을 시드로 사용하면 실행 시점에 따라 다른 난수를 얻을 수 있습니다.
    
    2-4. 특정 범위의 난수 생성하기
        => int number = std::rand() % 10 + 1;
        => 특정한 수를 % 10 -> 10 나머지 연산자는 0 ~ 9
        => % 연산을 사용하면 일부 숫자의 발생 확률이 약간 달라지는 모듈로 편향(Modulo Bias)이 발생할 수 있습니다.


3. C++ <random>
    => 난수 생성 라이브러리입니다.
    => 일반적인 C++ 프로그램에서 난수를 생성할 떄 권장하는 라이브러리입니다.
    => #include <random>

    3-1. std::random_device rd;
        => 시드를 얻기 위한 난수 생성 객체입니다.
    
    3-2. std::mt19937 gen(rd());
        => 실제로 의사 난수를 생성하는 엔진입니다.
        => mt19937은 메르센 트위스터(Mersenne Twister)라는 알고리즘을 사용합니다.
        => rd()가 반환한 값을 초기 시드로 사용합니다.
    
    3-3. std::uniform_int_distribution<int> dist(1, 10);
        => 난수를 어떤 범위와 확률 분포로 생성할지 결정하는 객체입니다.
        => 1과 10이 모두 포함
    
    3-4. int number = dist(gen);
        => 실제 난수를 하나 생성하는 코드
        => gen이 의사 난수를 생성하고, dist가 그것을 지정한 범위의 정수로 변환합니다.
