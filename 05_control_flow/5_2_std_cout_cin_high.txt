1. std :: cout, std :: cin은 표준 출력과 표준 입력을 처리합니다.
    => 기본 연결 대상은 cout은 콘솔 화면, cin은 키보드 입력입니다.
    => 자료형은 std :: ostream, std :: istream


2. std :: cout의 구조
    2-1. std::cout << 10;
    2-2. std::cout은 std::ostream 출력 스트림 클래스의 객체입니다.
    2-3. std :: endl과 \n의 차이
        => 둘 다 줄바꿈을 수행합니다.
        => endl은 개행 문자 출력 + 출력 버퍼 flush
        => \n은 개행 문자를 출력하지만 명시적으로 flush하지 않습니다.


3. std :: cin의 구조
    3-1. int age; / std::cin >> age;
    3-2. std::cin은 std::istream 입력 스트림 클래스의 객체입니다.

    3-3. int a = 0;
        int b = 0;

        std::cin >> a >> b;

        std::cout << a << ", " << b << '\n';
        10 20 키보드 입력
    3-4. 내부적으로 표준 입력 스트림에 10, 20이 순차적으로 들어옵니다.
        => std::cin >> a(10) 처리, std::cin >> b(20) 처리
    
    3-5. std::cin은 정수나 문자열 등을 입력받으면 기본적으로 앞쪽의 공백 문자를 건너뜁니다.
        => 10 20 / 10 \n 20 /    10    20 -> 전부 a=10, b=20 처리합니다.
    
    3-6. std :: cin의 문자열 입력 문제
        => Hong Won Tae를 키보드 입력
        => Hong만 받아들입니다.
        => 기본적으로 공백 문자에서 문자열 추출을 멈춥니다.
        => 공백을 포함한 한 줄을 읽으려면 std::getline()를 사용해야 합니다.
    
    3-7. cin과 getline을 함께 사용할 때 주의점
        => int age;
            std::string name;

            std::cin >> age;
            std::getline(std::cin, name);
        => 사용자가 25 입력하고 enter, std :: cin은 숫자만 읽고 개행문자를 입력 버퍼에 남겨 둘 수 있습니다.
        => std::getline()이 그 개행 문자를 읽어서 빈 문자열을 반환합니다.
        => std::cin.ignore(std::numeric_limits<std::streamsize>::max(),'\n');
            -> ignore은 지정한 범위만큼 입력을 버리는 함수입니다.
    
    3-8. std::cin의 입력 실패 처리
        => std :: cin은 입력의 성공-실패에 따라 반환값을 bool 형태로 반환합니다.
        => if문으로 확인할 수 있습니다.
