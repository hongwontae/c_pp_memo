1. 2의 보수
    1-1. 보수란 어떤 기준값을 만들기 위해 부족한 만큼 채워 주는 수입니다.
    1-2. 7의 10에 대한 보수는 3입니다.
    1-3. 컴퓨터에서 2의 보수는 n비트 이진수에서 2^n을 기준으로 구하는 보수입니다.
        => 5라는 값은 0101로 표현되고 4개의 bit가 존재합니다.
        => 2^4 = 16, 5에 대한 16의 보수는 11입니다.
        => 0000 0101 | 0000 1011 -> 1 0000 0000 -> 1은 버림 -> 0
    


2. 음수 -5를 컴퓨터가 표현하는 방법
    => 양수 5를 이진수로 표현합니다. 0000 0101
    => 모든 비트를 반전시킵니다. 1111 1010
    => 1을 더합니다. 1111 1011
    => 1111 1011이 음수 -5를 표현하는 컴퓨터 방식입니다.
    => 1111 1011 + 0000 0101 -> 1 0000 0000 -> 1을 제외 -> 0
