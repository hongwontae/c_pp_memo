1. 부동 소수점 수
    1-1. float 
        => 실수를 표현하는 4byte 데이터 타입입니다.
    
    1-2. double
        => 실수를 표현하는 8byte 데이터 타입입니다.
    
    1-3. long double
        => 실수를 표현하는 8 | 12 | 16 byte 데이터 타입입니다. (플랫폼마다 다름)
        => long double | double long 둘 다 문법적으로 허용합니다.
        => 현 맥 OS에서는 16byte가 출력됩니다.


2. 부동 소수점을 표현하는 데이터 타입은 내부적으로 비트를 아래와 같이 사용합니다.
    2-1. 가장 맨 앞의 하나의 비트는 부호를 표현합니다.
    2-2. 나머지는 지수와 가수의 비트로 사용합니다. -> 지수는 정수 / 가수는 실수
        => 지수와 가수가 얼마나 비트를 사용할지는 환경에 따라 다릅니다.


3. inf, -inf, nan(ind)는 부동 소수점 자료형에서 나타날 수 있는 특별한 값입니다.
    3-1. inf -> 양의 무한대 / 실수 연산의 오버플로 또는 0으로 나누는 연산에 발생
    3-2. -inf -> 음의 무한대
    3-3. nan(ind) -> 숫자로 표현할 수 없는 부정형 결과 / ind -> indeterminate


4. 지수 표기법 e
    3-1. e는 10의 거듭제곱을 의미하는 표기 기호입니다.
    3-2. 3.14e1 -> 31.4
    3-3. 3.14e-1 -> 0.312
