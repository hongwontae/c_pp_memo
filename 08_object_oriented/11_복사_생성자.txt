1. 복사 생성자
    => 기존에 존재하는 객체를 이용해서 새로운 객체를 생성하는 생성자입니다.


2. 예시
    => Student a("Hong", 20);
    => Student b = a;
    => 이 떄 복사 생성자가 호출됩니다.
    => 객체를 대입 연산자의 피연산자로 두면 새로운 객체 b를 생성하면서 a의 값을 복사합니다.


3. 복사 생성자 형태
    => Student(const Student& other) 
        : name(other.name), age(other.age) {}
    => 객체의 참조가 전달되며 그 참조는 변경할 수 없습니다.
    => 복사 생성자는 객체를 값으로 전달받을 수 없습니다.


4. 복사 생성자를 직접 작성하지 않아도 컴파일러가 암시적으로 복사 생성자를 선언합니다.
    => 기본적으로 제공되는 복사 생성자는 각 멤버를 복사합니다.
