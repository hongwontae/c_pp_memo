1. 정적 멤버 변수
    1-1. 클래스에 속하며, 해당 클래스로 생성한 모든 객체가 공유하는 변수입니다.
    1-2. 멤버 변수를 선언할 떄 static int age 처럼 static를 앞에 붙입니다.
    1-3. 해당 멤버 변수를 정적 멤버 변수라고 부르며, 클래스 전체에서 하나의 변수를 공유하게 됩니다.
    
    1-4. 정적 멤버 변수의 선언과 정의
        => 정적 멤버 변수를 만들 떄는 선언과 정의를 분리해야 합니다.
        => 클래스 내부에서는 정의
        => 클래스 외부, 전역에서 int 클래스명::멤버_변수 = 0; 정의합니다.
        => 생성자 멤버 목록에서는 정적 멤버 변수를 초기화할 수 없습니다.
            -> 멤버 초기화 목록은 현재 생성 중인 객체의 비정적 데이터 멤버와 기반 클래스를 초기화합니다.
        => 일반 생성자 함수에서는 정적 멤버 변수의 값을 초기화할 수 있습니다.
        => C++ 17에서는 inline static int age = 0; 처럼 클래스 내부에서 선언 + 정의를 할 수 있습니다.
    
    1-5. 정적 멤버 변수는 객체 없이 접근할 수 있습니다.
        => 정적 멤버 변수는 특정 객체에 소속된 변수가 아니라 클래스에 소속된 변수이기 떄문입니다.
        => 이 떄 클래스명 :: 멤버_변수 -> 이렇게 접근합니다.
    
    1-6. 정적 멤버 변수는 초기화된 정적 변수는 .data 영역에 0으로 초기화된 변수는 BSS 영역에 배치될 수 있습니다.

    1-7. 정적 멤버 변수는 생성된 객체 개수를 관리할 떄 주로 사용합니다.


2. 정적 멤버 함수
    2-1. 특정 객체에 속하지 않고, 클래스에 속하는 멤버 함수입니다.
    2-2. 정적 멤버 함수의 큰 특징은 this 포인터가 존재하지 않습니다.
    2-3. 정적 멤버 함수 선언 방법
        => static 반환형 함수_이름() {};
        => static void printf() {};
    2-4. 호출 방법
        => 클래스_이름 :: 멤버함수();
        => 객체를 만들고 객체에서 정적 멤버 함수를 호출하는 것도 가능합니다.
    
    2-5. 정적 멤버 함수는 정적 멤버 변수에 접근할 수 있지만 일반 멤버 변수에 접근할 수 없습니다.
        => this 포인터가 존재하지 않기 떄문입니다.
        => 접근할 객체를 명시적으로 전달하면 가능합니다. -> 참조 
        => 일반 멤버 함수 접근도 불가능
    
    2-6. 정적 멤버 함수는 const를 붙일 수 없습니다.
        => static void print const () {} -> 불가
