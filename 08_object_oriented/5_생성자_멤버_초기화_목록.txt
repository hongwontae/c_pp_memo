1. 생성자 멤버 초기화 목록 (Member Initializer List)
    => 생성자가 실행되기 전에 클래스의 멤버 변수를 직접 초기화하는 문법입니다.


2. 예시
    class Student {
    private:
        std::string name;
        int age;

    public:
        Student(std::string n, int a)
            : name{n}, age{a}
        {
        }
    };

    2-1. :은 멤버 초기화 목록의 시작입니다.
    2-2. name{n}, age{a}는 멤버 변수를 매개변수 값을 초기화합니다.
    2-3. {}은 생성자 함수 본문입니다.


3. 생성자 함수를 사용하면 생성자 본문에 들어가기 전에 멤버 변수가 생성됩니다.
    => 그 다음 생성자 본문이 실행됩니다.
    => 존재하는 멤버 변수에 매개변수로 받은 값을 대입하는 방식입니다.


4. 멤버 초기화 목록을 사용하면 생성자 본문을 실행하기 전에 n을 이용해 초기화합니다.
    => 그 다음 생성자 본문이 실행됩니다. -> 대체로 아무것도 없음


5. C++에서는 클래스 객체를 생성하면, 생성자 본문 {}이 실행되기 전까지 멤버 변수들의 초기화가 먼저 이루어져야 합니다.


6. 생성자 멤버 초기화를 하는 이유
    6-1. const 멤버 변수
        => const 멤버 변수는 초기화가 되면 다시 수정할 수 없습니다.
        => 일반적으로 생성자 함수를 사용하면 멤버 변수를 먼저 생성하기 떄문에 
            생성자 멤버 초기화를 통해 값을 받아서 초기화해야 합니다.
    
    6-2. 참조 멤버 변수
        => 참조 변수도 참조할 값이 없이 초기화될 수 없습니다.
        => 6-1과 동일한 기전으로 생성자 멤버 초기화를 사용합니다.


7. C++은 클래스 내부에 멤버 변수를 선언한 순서대로 초기화합니다.
