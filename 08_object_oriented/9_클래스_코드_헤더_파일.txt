1. 하나의 파일에 클래스 선언과 구현, 그리고 클래스를 사용하는 로직이 존재할 떄,
    파일을 3개로 나눕니다. -> 일반적인 C++ 프로젝트에서는 분리해서 관리합니다.
    => 프로그램 시작점, 클래스 선언, 클래스 멤버 함수 정의


2. 클래스 선언 헤더 파일(.h)
    => 클래스가 어떤 멤버 변수와 멤버 함수를 가지고 있는지 작성합니다.
    => 생성자 함수와 멤버 함수의 정의를 제거합니다. -> 선언만 존재


3. 멤버 함수 정의 파일(.cpp)
    => 반환 타입 클래스_이름 :: 멤버_함수 () {}
        -> 멤버 함수를 정의할 떄 해당 문법을 사용합니다.
    => 클래스_이름 :: 생성자_함수(){}
        -> 생성자 함수를 정의할 떄 해당 문법을 사용합니다.
    => 범위 지정 연산자(::)를 통해 해당 정의가 클래스에 속한다고 표현해야 합니다.
