1. 소멸자
    => 객체의 수명이 끝날 때 자동으로 호출되는 특별한 멤버 함수입니다.


2. 소멸자의 기본 문법
    ~Student() {
        std::cout << "소멸자 호출\n";
    }

    => ~클래스_이름(){}
    => 생성자와 마찬가지로 반환 타입이 없습니다.


3. C++에서 객체의 수명이 끝나는 시점을 언어가 관리합니다.
    => 객체가 존재하는 블록의 수명이 끝나면 소멸자가 자동으로 호출됩니다.
    => 소멸자는 함수 종료시에만 호출되는 것이 아니라, 객체가 속한 블록의 수명이 끝날 떄도 호출됩니다.


4. 소멸자가 필요한 이유
    class Student {
    private:
        int* score;

    public:
        Student() {
            score = new int{100};
        }
    };

    4-1. Student st;
    4-2. st.score는 포인터 변수이고 이 주소에 heap 영역에 int 데이터가 존재합니다.
    4-3. main이 종료 -> st 객체 자체는 정리되지만 heap 영역의 int 데이터는 자동으로 해제되지 않습니다.
        => 메모리 누수가 발생합니다.
    4-4. 이 떄 소멸자가 필요합니다.


5. 소멸자를 이용한 메모리 해제
    ~Student() {
        delete score;
        std::cout << "소멸자 호출\n";
    }

    5-1. main이 종료 
    5-2. ~Student 소멸자를 실행
    5-3. delete score를 통해 메모리 해제


6. 하나의 클래스에서 생성과 정리를 관리할 수 있게 됩니다.


7. new로 생성한 객체의 소멸자 호출 시점
    int main() {
        Student* st = new Student;
    }

    7-1. main이 끝나도 st 포인터 변수는 종료되지만 heap의 객체는 남아 있습니다.
    7-2. delete st;를 해야 해제됩니다.
        => 그리고 이 떄 Student의 소멸자가 호출되고 내부의 score의 동적 영역이 해제됩니다.


8. 같은 블록 안에서 생성한 지역 객체들은 일반적으로 생성된 순서의 역순으로 소멸합니다.
    => 역순으로 소멸자 호출
