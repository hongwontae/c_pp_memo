1. Class
    1-1. 여러 데이터와 함수를 하나의 타입으로 묶어서 정의할 수 있는 C++ 문법입니다.
    1-2. 문법 및 예시
        class Player {
        public:
            int hp;
            int attack;
            int level;
        };

        Player p1{100, 20, 1};
        Player p2{200, 30, 5};
        => class className {기술할 멤버}
        => p1, p2는 서로 다른 주소 값을 가진 별도의 객체이자 변수입니다.
    
    1-3. 접근
        => .(멤버 접근자)를 통해 객체의 멤버에 접근할 수 있습니다.
    1-4. 객체는 함수를 가질 수 있습니다.


2. 객체 메모리 공간
    Player p1;
    Player* p2 = new Player;

    => p1은 Stack, p2는 Heap 영역에 존재합니다.
    => new를 사용해서 클래스를 통한 객체를 생성하면 포인터가 결과값입니다.
    => 그리고 그 객체는 힙 영역에 존재하고 힙 영역의 주소 값은 스택에 존재합니다.
    => 이 떄 delete를 사용해서 사용자가 직접 해제해야 합니다.


3. 클래스는 타입으로 사용될 수 있고 클래스 객체는 매개변수로 받을 수 있습니다.
    => void copy_from (Student stu)
    => void copy_from (Student & stu)
    => void copy_from (const Student & stu)
