1. C++ 클래스 객체 초기화 문법
    => 객체 생성은 객체의 수명이 시작되는 과정이고, 초기화는 객체가 처음 어떤 상태를 갖게 되는지 결정하는 과정입니다.

    #include <string>

    class Student {
    public:
        std::string name;
        int age;
    };

    1-1. 기본 초기화
        => Student stu;
        => std::string name은 string class에 의해 빈 문자열 / int는 초기화되지 않습니다.
    
    1-2. 값 초기화
        => Student stu{};
        => stu.name == ""; // true
        => stu.age == 0;   // true
        => 일반적으로 0이 되거나, 빈 문자열, 0.0.. 
    
    1-3. 직접 리스트 초기화
        => Student stu{"hong", 10};
        => class의 선언 순서에 따라 초기화 됩니다.
        => 이 때 private이라면 컴파일 에러가 발생합니다.
        => 중괄호에 전달된 값이 멤버 변수 선언 순서대로 초기화되는 것을 집합 초기화라고 합니다.
        => C++ 20부터는 ()를 이용한 집합 초기화가 가능합니다.
    
    1-4. 복사 리스트 초기화
        => Student stu = {"hong", 10};
        => 3과 결과는 같습니다.
    
    1-5. 복사 초기화
        => Student stu1{"hong", 10};
        => Student stu2 = stu1;
        => 컴파일러가 만들어주는 복사 생성자가 각 멤버를 초기화합니다.
    
    1-6. 객체를 생성할 떄 리스트 {} 초기화는 생성자 함수에 데이터를 넘길 떄 형변환을 허용하지 않습니다.
    1-7. () 초기화는 형변환을 허용합니다.


2. C++ 생성자

    2-1. 객체가 초기화될 때 호출되는 특별한 멤버 함수입니다.
    2-2. 생성자 특징
        => 생성자의 이름은 클래스 이름과 동일합니다.
        => 반환 타입이 없습니다. void도 작성하지 않습니다.
        => 객체를 초기화할 때 자동으로 호출됩니다.
        => 매개변수를 받을 수 있습니다.
        => 여러 개 정의할 수 있습니다. (오버로딩)
    
    2-3. 객체 생성과 생성자 실행 흐름
        => 객체 선언 -> 객체를 위한 저장 공간 확보 -> 멤버 초기화 및 생성자 본문 실행 -> 초기화 완료된 객체
    
    2-4. 객체에서 생성자 함수를 호출하는 것은 불가능합니다.

    2-5. 기본 생성자
        => 기본 생성자는 인수를 전달하지 않고 호출할 수 있는 생성자입니다.
        class Student {
        public:
            Student() {
                std::cout << "기본 생성자 호출\n";
            }
        };
        => Student stu1; Student stu2{}; Student stu3 = Student{};
        => 위 모두 기본 생성자를 호출합니다.
        => 생성자를 아예 정의하지 않아도 컴파일러가 기본 생성자를 암시적으로 선언해줍니다.
            -> 다만 모든 멤버 변수가 0으로 초기화되는 것은 아닙니다.
    
    2-6. 매개변수가 존재하는 생성자
        => Student stu1("hong", 20); Student stu2{"kim", 25};
        => 이 떄 생성자 함수가 호출되면서 매개변수에 인자의 값이 들어갑니다.
    
    2-7. 생성자 오버로딩
        => C++은 생성자를 여러 개 정의할 수 있습니다.
        => 객체를 생성하는 방식에 따라 서로 다른 생성자가 호출됩니다.
        => Student stu1; Student stu1; Student stu3("hong", 20);
    
    2-8. 생성자에 의한 암시적 변환
        Student(int a) {
            age = a;
            std::cout << "생성자 호출\n";
        }
        => Student stu = 20;
        => 생성자 호출 / age = 20;
        => 컴파일러가 Student 클래스의 생성자를 확인하고 int 매개변수라고 임시로 판단해서 초기화 해버립니다.
