1. 위임 생성자 
    => 하나의 생성자가 같은 클래스의 다른 생성자를 호출하여 초기화 작업을 맡기는 기능입니다.


2. Visual Studio oop_4 예시
    2-1. Student() 호출 시작
        => 기본 생성자 선택
    2-2. Student{"Unknown", 0} 위임
        => 인수 두 개를 받는 생성자 실행
    2-3. name, age 초기화
        => name = "Unknown", age = 0
    2-4. 인수 두 개를 받는 생성자의 본문 실행
        => "메인 생성자 호출" 출력
    2-5. Student() 본문 실행
        => "기본 생성자 호출" 출력
    
    => 위임받은 생성자의 초기화와 본문 실행이 끝난 다음, 위임한 생성자의 본문이 실행됩니다.


3. 위임 생성자는 객체를 두 번 생성하는 것이 아닙니다.
    => Student st;를 실행하면 Student()와 Student(std::string, int)라는 두 생성자가 관여하지만
        생성되는 객체는 하나입니다.
    => 두 생성자가 같은 객체의 초기화 과정에 참여합니다.


4. 위임 생성자 사용 시 주의사항
    => 위임 생성자를 사용했다면 객체의 초기화 작업을 다른 생성자에게 맡긴 것입니다.
    => 위임 생성자 목록에는 다른 멤버 초기화 항목을 함께 작성할 수 없습니다.
    => 위임 생성자가 끝난 뒤 실행되는 본문에서 값을 변경할 수 있습니다.


5. 위임 생성자는 여러 단계로 연결할 수 있습니다.
