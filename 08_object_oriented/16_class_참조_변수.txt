1. 참조 멤버 변수
    1-1. 참조 멤버 변수 class 내부에 선언하면 생성자 초기화 목록 + 생성자 매개변수로 참조 변수 사용해야 합니다.
        => 참조 변수는 참조할 대상이 없다면 컴파일 오류
        => 매개변수로 일반 변수를 받으면 복사된 값을 받습니다. -> 완전히 다른 값 참조
    
    1-2. 참조 멤버 변수 변경
        => 참조 멤버 변수가 초기화되었다면 참조의 대상이 변경되든, 참조가 변경되든 동일하게 값 변경이 일어납니다.
        => 참조 멤버 변수도 일반 참조 변수와 동일하게 한 번 참조 대상이 결정되면 변경할 수 없습니다.
    


2. const 참조 멤버 변수
    2-1. const int& age;
    2-2. 참조하는 대상의 값을 멤버 참조 변수 age로 변경할 수 없다는 의미입니다.
        => 다른 원본 변수까지 const가 되는 것은 아닙니다.


3. const 객체와 참조 멤버 변수
    3-1. const Student stu {30};
        => 일반 참조 변수가 존재
    3-2. stu.setAge(20);
        => 가능
    3-3. Student 객체 자체의 상태를 변경하는 것이 아니라,
         참조하고 있는 외부 변수 num의 값을 변경하는 것이기에 가능합니다.
