1.  클래스 중첩 타입
    => 클래스 내부에 선언된 자료형을 의미합니다.


2. 중첩 구조체
    => oop_test_12 참고
    => Student::Address addr{"Seoul", 12345};
    => Student::Address는 자료형, addr은 변수 이름, {"Seoul, 12345"}는 초기화입니다.


3. 중첩 클래스
    => oop_test_13 참고
    => Inner는 Outer 클래스 내부에 선언된 별도의 클래스 타입입니다.
    => 중첩 클래스는 바깥 클래스의 private 멤버에 접근할 수 있습니다.
    => C++에서 중첩 클래스는 바깥 클래스의 멤버와 동일한 접근 권한을 가지기 때문입니다.
    => 그러나 Inner 객체에는 Outer 객체를 가리키는 this 포인터가 없기 떄문에 매개변수로 Outer를 받아야 합니다.

5. 중첩 alias
    => using과 typedef를 사용해서 멤버 변수를 선언할 수 있습니다.


6. 중첩 타입은 접근 지정자가 적용됩니다.
