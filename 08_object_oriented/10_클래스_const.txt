1. const 멤버 변수
    1-1. class의 멤버 변수에 const가 붙어 있는 것을 의미합니다.
    1-2. 객체를 생성한 이후에 const가 붙에 있는 멤버 변수는 변경이 불가능합니다.
    1-3. 이러한 const 멤버 변수는 멤버 초기화 목록을 사용해야 합니다.
        => 생성자 함수를 사용해서 초기화하면 초기화 되지 않습니다.
        => 생성자 함수가 실행되기 전에 멤버 변수가 초기화되기 떄문입니다.


2. const 멤버 함수
    => int getAge() const {return age;}
    => 문법 : 자료형 함수_이름() const {...};
    => const가 붙은 멤버 함수는 현재 객체의 일반 멤버 변수를 수정할 수 없도록 제한합니다.
    => const 멤버 함수 내부에서 일반 멤버 함수를 호출하는 것도 제한합니다.


3. const 객체
    => const Student stu(20);
    => const 객체는 const 멤버 함수만 호출할 수 있습니다. -> 일반 멤버 함수 호출 불가
    => 객체의 값을 읽는 함수에는 보통 const를 붙여줍니다.


4. const 멤버 함수와 this 포인터
    => 일반 멤버 함수에서 this의 타입은 개념적으로 클래스명 * const this 입니다.
    => 즉, this 포인터 자체는 다른 객체를 가리키도록 바꿀 수 없지만, 가리키는 객체의 멤버는 수정할 수 있습니다.

    => const 멤버 함수의 타입은 개념적으로 const Student* const this 입니다.
    => 포인터 자체도 못 바꾸고 가리키는 객체도 수정할 수 없습니다.
