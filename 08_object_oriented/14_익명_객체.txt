1. 익명 객체
    => 이름이 없는 객체를 의미합니다.


2. 익명 객체 생성 방법
    => 클래스명(arg..);
    => 생성된 임시 객체는 해당 표현식이 끝날 떄 소멸합니다. -> 소멸 생성자 호출됩니다.


3. 익명 객체 멤버 함수 호출
    => 클래스명(arg..).멤버_함수();


4. 익명 객체는 함수의 인수로 사용할 수 있습니다.
    => 매개 변수가 객체일 떄 전달 할 수 있습니다.


5. 익명 객체는 복사 생성자를 호출하지 않고 일반 생성자 + 소멸 생성자만 호출합니다.


6. 익명 객체 수명
    6-1. const Student& a = Student(20);
        => 임시 객체가 a에 바인딩되고 멤버 변수를 수정할 수 없습니다.
        => 그리고 임시 객체의 수명이 지역 참조 변수 a의 수명까지 연장됩니다.
    
    6-2. Student& a = Student(20);  // 컴파일 오류!
        => Student(20)은 임시 객체를 나타내는 rvalue(정확히는 prvalue) 표현식입니다.
        => Student&는 비const lvalue 참조이므로 이런 임시 객체에 직접 바인딩할 수 없습니다.
