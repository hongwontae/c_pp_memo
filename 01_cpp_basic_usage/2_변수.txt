1. 변수
    => 메모리를 사용하는 문법입니다.
    => 변수는 메모리의 주소와 값의 정보가 들어있습니다.

2. left value / right value
    => left value : 변수의 메모리 공간
    => right value : 변수의 메모리 공간의 값

3. 초기화
    => 초기화를 하지 않으면 쓰레기 값이 들어있을 수 있습니다.
    => 초기화 하지 않은 변수를 사용한 실행 파일을 빌드 시 그냥 실행이되거나 에러가 발생할 수 있습니다.
    => 초기화를 하지 않으면 의도하지 않은 행동이 되며 나중에 큰 문제가 발생할 수 있습니다.
    => 항상 변수를 정의할 떄 선언과 함께 초기화를 해주는 습관이 필요합니다.
