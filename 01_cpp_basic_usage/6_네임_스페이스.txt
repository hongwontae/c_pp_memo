1. 네임 스페이스
    => 이름이 충돌하는 것을 방지하기 위해 이름들을 논리적으로 묶어 놓는 공간입니다.


2. namespace가 필요한 이유
    2-1. 같은 범위의 print() 함수를 정의하면 충돌이 발생합니다.
    2-2. 각각의 함수를 namespace 문법으로 묶으면 공존할 수 있습니다.


3. namespace 문법
    3-1. namespace A {
            printf(){}
    }
    3-2. namespace의 함수를 사용하려면 :: (범위 지정 연산자)를 사용합니다.
    3-3. A :: print();


4. std :: cout
    4-1. std는 C++ 표준 라이브러리가 사용하는 네임스페이스입니다.
    4-2. std :: cout은 네임스페이스 std에 속한 cout이라는 함수를 사용하겠다는 의미입니다.


5. using namespace std;
    => std 네임스페이스의 이름없이 해당 범위의 함수나 변수를 사용할 수 있습니다.
