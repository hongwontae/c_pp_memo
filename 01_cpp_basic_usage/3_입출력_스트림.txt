1. 입출력 스트림
    1-1. #include <iostram> 
        => 표준 입출력 스트림 헤더 파일 -> iostram입니다.
        => c++에서 iostram을 포함하면 std::cout, std::cin, std::endl.. 같은 입출력 객체 사용할 수 있습니다.

    1-2. cout
        => 콘솔 장치로 데이터를 보내는데 사용하는 객체입니다.
        => std :: cout << "hello-world""
        => c에서 printf()와 비슷한 동작을 합니다.

    1-3. cin
        => 사용자 입력을 받는데 사용하는 객체입니다.
        => std :: cin >> variable;
        => c에서 scanf()와 비슷한 동작을 합니다.

    1-4. << / >>
        => <<은 출력 연산자로 데이터를 출력 스트림으로 보낸다는 의미입니다.
        => >>은 입력 연산자로 입력 스트림에서 값을 읽어 변수에 저장한다는 의미입니다.
        => >>, <<은 비트 연산자로도 사용되며 cout, cin과 함께 사용할 때는 입/출력 연산자로 사용됩니다.

    1-5. endl
        => std::endl
        => 줄바꿈을 수행하고 출력 스트림을 비우는(flush) 객체입니다.
        => \n과 비슷한 동작입니다. -> 출력 스트림 비우는 차이가 존재
        
    1-6. std가 붙는 이유
        => std는 표준 라이브러리의 이름 공간입니다. (namespace)
        => cout, cin, endl -> 표준 라이브러리 std라는 이름 공간에 속함
        => using namespace std를 사용하면 std :: 를 생략할 수 있습니다.
        

2. cout << &a[2] << std::endl;
    2-1. &a[2]의 주소 계산
    2-2. 주소를 출력 스트림에 삽입
    2-3. std:endl를 실행
    2-4. 줄바꿈 문자 삽입
    2-5. flush()로 출력 스트림 비우기


3. 출력 버퍼
    => cout이 자동으로 버퍼를 관리하고 필요한 시점에 출력 데이터를 전달합니다.
    => std::endl의 flush()가 출력하기 위한 필수 조건이 아닙니다.
    => cout << a[1]; -> 정상적으로 출력됩니다.
