1. 선언이란 어떤 형식의 변수, 함수, 타입 등이 존재한다고 알리는 것입니다.
    => 같은 타입의 변수를 동시에 선언할 수 있습니다.
    => int a, b, c;

2. 정의란 실제로 객체를 만들거나 함수의 구현을 제공하는 것입니다.
    => 같은 타입의 변수를 선언할 떄 동시에 정의할 수 있습니다.
    => int a = 100, b = 100, c = 300;

3. c++에서 선언은 헤더 파일에 작성하고 cpp 파일에서 헤더의 정의를 하며 cpp main 함수에 사용하는 흐름으로 이어집니다.

4. 컴파일 할 떄 선언이 안된 함수나 변수 사용시 컴파일 에러가 발생합니다.
    => 헤더 파일을 기재하거나 #include <> | ""
    => 상단에 선언을 작성하면 컴파일 에러가 발생하지 않습니다.

5. 헤더 파일은 존재하나 정의가 없다면 링크 에러가 발생합니다.
    => 링크 타임에 링커가 선언에 해당하는 정의를 찾아서 연결하기 때문입니다.

6. 초기화
    6-1. 복사 초기화
        => int a = 10;
        => 암시적 형 변환을 허용합니다.
    
    6-2. 직접 초기화
        => int b(30);
        => 암시적 형 변환을 허용합니다.
        => 클래스 관련 -> 나중에 확인
    
    6-3. 리스트 초기화
        => int c{40};
        => 암시적 형 변환을 허용하지 않습니다.
        => 배열과 구조체에 사용할 수 있습니다. -> 나중에 확인
