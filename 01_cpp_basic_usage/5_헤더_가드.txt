1. 선언과 정의를 분리하면 연결하는 링크 타임에 에러가 발생할 수 있습니다.
    => 컴파일 타임은 선언만 존재하면 성공합니다.

2. 헤더 가드 (include guard)
    2-1. 하나의 헤더 파일이 한 번의 컴파일 과정에서 중복으로 포함되는 것을 방지하는 전처리기 기법입니다.
    2-2.  #include는 해당 헤더 파일의 내용을 그 위치에 삽입하는 것처럼 처리합니다.

3. 헤더 가드의 기본 구조
    #ifndef B_H
    #define B_H

    typedef struct {
        int value;
    } Data;

    #endif
    => B_H라는 매크로가 정의되어 있지 않다면 -> #ifndef
    => B_H라는 매크로를 정의하고 헤더 파일 내용을 처리합니다. -> #define
    => 조건부 컴파일의 끝 -> #endif


4. 매크로는 일종의 표시입니다.
    => 첫 번쨰 헤더에 들어왔을 떄 매크로로 표시를 하고 표시를 보고 헤더를 포함할지 말지 결정합니다.


5. #pragma once
    => 3의 동작을 하는 간단한 문법입니다.
