1. 진법
    => 진법이란 숫자를 표현할 떄 몇 개의 숫자 기호를 사용하는지 나타내는 체계입니다.


2. 10진법
    2-1. 10진법은 자릿수가 왼쪽으로 한 칸 이동할 때마다 자릿값이 10배씩 증가합니다.
    2-2. 123 -> 10^2*1 + 10^1*2 + 10^0*3;

3. 2진법
    3-1. 2진법은 자릿수가 왼쪽으로 한 칸 이동할 때마다 자릿값이 2배씩 증가합니다.
    3-2. 1100 -> 2^3*1 + 2^2*1 + 2^1*0 + 2^0*0;


4. 2진수를 10진수로 변환하기
    => 각 자릿수에 해당하는 2의 거듭제곱을 곱한 다음 모두 더하면 됩니다.
    => 즉, 0011 0101이라면 2^7 ~ 2^0 -> 1이 들어간 숫자만 더하면 됩니다.


5. 10진수를 2진수로 변환하기
    => 2로 계속 나누고 나머지가 존재하면 1을 기록하고 역순으로 기재합니다.
    => 13 / 2 -> 6 3 1 0 -> 1 1 0 1


6. signed와 unsigned는 메모리에 저장된 비트 자체가 다른게 아니라 동일한 비트 패턴을 어떤 정수로 해석하느냐의 차이가 존재합니다.
    6-1. 음수를 표현하기 위해 2의 보수 방식을 사용합니다.
    6-2. signed/unsigned char의 범위 -> 둘 다 1byte / -128 ~ 127 | 0 ~ 255
    6-3. unsigned는 8개 비트 모두 0 이상의 양의 정수를 표현하는데 사용합니다. 2^7-1 -> 255 (이 떄 0도 포함이라 255까지 표현가능)
    6-4. signed의 가장 왼쪽 비트의 자릿값은 128이 아니라 -128이라는 가중치이며 부호 비트라고 부릅니다.
        => -128 64 32 16 | 8 4 2 1
        => signed에서 1111 1111은 -1을 의미합니다. -> -128 + 64 + 32 + 16 + 8 + 4 + 2 + 1 = -1;
    6-5. 양수로 표현할 떄는 singed와 unsigned가 동일한 비트 패턴을 사용합니다.
    6-6. 0을 표현할 떄 signed와 unsigned 모두 0000 0000 비트 패턴을 사용합니다.
    6-7. 음수 표현 -> signed만 가능, 5 -> -5, 이진수 5의 비트를 반전하고 +1을 하면 2의 보수가 되고 이를 음수라고 판단합니다.
        => 2의 보수가 되는 이유는 가장 왼쪽 비트를 -128이라고 판단하기 때문입니다.
