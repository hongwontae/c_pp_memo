1. 관계 연산자
    1-1. 두 피연산자의 값을 비교하여 bool 자료형인 true | false를 반환하는 연산자입니다.
    1-2. >, >=, <, <= -> 관계 연산자 / ==, != -> 동등 비교 연산자라고 부릅니다.
    1-3. ==, !=
        => 피연산자 값이 일치하면 true, 다르면 false를 반환합니다.
        => != 피연산자의 값이 다르면 ture, 값이 같으면 false를 반환합니다.
    1-4. >, >=, <, <=
        => 값을 비교해서 true/false를 반환합니다.


2. 부동 소수점 오차
    2-1. 컴퓨터는 소수를 저장할 떄 이진수로 변환하는 과정에서 일부 데이터 소실이 존재합니다.
    2-2. 그래서 0.1과 0.1을 double로 저장하고 동등 비교 연산자로 비교해도 false가 반환됩니다.
    2-3. 이 떄 epsilon이라는 부동 소수점 오차 범위를 만들어내서 두 값의 차이가 앱실론보다 적으면 값이 같다고 판단해야 합니다.
