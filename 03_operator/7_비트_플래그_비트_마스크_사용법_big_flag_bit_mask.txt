1. 비트 플래그
    1-1. 비트 플래그는 하나의 정수형 변수에 여러 개의 상태를 저장하고 관리하는 기법입니다.
    1-2. unsigned char flags = 0b 0000 0101; -> 하나의 비트가 하나의 상태라고 가정했을 떄
     여러 상태를 관리할 수 있습니다.


2. 비트 플래그를 정의하는 방법
    2-1. 직접 이진수로 작성하기보다 << 연산자를 통해서 정의합니다.
        => constexpr unsigned char RUN    = 1 << 0;
        => constexpr unsigned char JUMP   = 1 << 1;
        => constexpr unsigned char ATTACK = 1 << 2;
        => constexpr unsigned char DEFEND = 1 << 3;
    2-2. 이렇게 사용하는 이유는 n 번째 비트만 1인 값을 만들기 위해서입니다.


3. 비트 플래그 설정하기 (or 연산자)
    3-1. unsigned char flags = 0;
    3-2. flags = flags | RUN; 
        => RUN 동작을 활성화시키는 연산입니다.
        => | 연산자는 맞대는 비트 중 하나가 1이라면 1로 만들기 return 합니다.
        => 00000001
    3-3. flags |= RUN;
        => 이렇게 복합 대입 비트 연산자를 통해 비트를 활성화할 수 있습니다.
    3-4. flags |= RUN | JUMP;
        => 한 번에 여러 플래그를 활성화할 수 있습니다.
        => RUN과 JUMP | -> 각자 자리 1 활성화
        => 이걸 |로 대입 -> flags에 RUN과 JUMP가 활성화 됩니다.


4. 비트 플래그 설정하기 (and 연산자)
    4-1. unsigned char flags = 0b00000101;
    4-2. 특정 기능이 플래그에서 활성화되어 있는지 확인하려면 if문과 and 연산자를 사용합니다.
    4-3. if (flags & RUN) {
            std::cout << "달리기 가능";
        } -> 00000101(flag) & 00000001(run) -> 1존재 -> true -> cout 출력


5. 비트 플래그 해제하기
    5-1. unsigned char flags = 0b 0000 0101;
    5-2. flags &= ~RUN;
        => 00000001(run) -> 11111110 (~run) -> 00000101(flag) & 11111110(~run) -> 00000100
        => 달리기 기능만 삭제되고 공격 기능은 유지되었습니다.


6. 비트 플래그 반전하기
    6-1. flags = 00000101
    6-2. flags ^= RUN;
        => 00000101(flag) ^ 00000001(run) -> 00000100
    6-3. 00000100(flag) ^ 00000001(run) -> 00000101
    6-4. xor 기능을 통해 토글 기능을 수행할 수 있습니다.


7. 여러 플래그 동시에 다루기
    constexpr unsigned int RUN    = 1u << 0;
    constexpr unsigned int JUMP   = 1u << 1;
    constexpr unsigned int ATTACK = 1u << 2;
    constexpr unsigned int DEFEND = 1u << 3;

    7-1. 여러 플래그 동시에 설정하기
        => unsigned int flags = 0;
        => flags |= RUN | JUMP | ATTACK;
        => 00000111

    7-2. 여러 플래그 동시에 해제하기
        => flags &= ~(RUN | JUMP);
    
    7-3. 여러 플래그가 모두 활성화되어 있는지 확인하기
        => if (flags & (RUN | JUMP)) {
            // ...
        }


8. 가장 중요한 개념은 char 자료형이더라도 비트 연산을 할 떄 int로 정수 승격이 됩니다.
    => char a = ~0b00000001
    => 내부적으로 11111111 11111111 11111111 11111110
    => 4294967294
    => 이것 말고도 부호 있는 정수를 사용하면 가장 왼쪽 비트가 활성화되어 음수가 될 수 도 있습니다.
    => ** 부호 없는 32 bit 정수형를 사용하는 것이 제일 좋습니다. **


9. 비트 마스크
    9-1. 특정 비트를 선택하거나 조작하기 위해 사용하는 비트 패턴입니다.
        => unsigned char data = 0b10110110;
        => unsigned char mask = 0b00000100;
        => 원하는 계산을 위해서 특정 비트를 만듭니다. -> 이를 비트 마스크라고 합니다.
