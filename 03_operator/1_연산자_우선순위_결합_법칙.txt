1. 연산자 우선순위와 결합 법칙
    1-1. 연산자 우선순위는 표현식을 어떻게 묶을지 결정하는 규칙입니다.
    1-2. 연산자 결합 법칙은 우선순위가 동일한 연산자인 경우
         왼쪽 결합 | 오른쪽 결합 -> 어느 부분을 먼저 계산할지를 결정하는 것입니다.
    1-3. 왼쪽 결합 -> 20 - 10 -5 -> (20-10) - 5 
    1-4. 오른쪽 결합 -> int a, b, c; a = b = c = 10; -> a = (b = (c = 10));


2. 주의해야 할 연산자 우선순위
    2-1. 증감 연산자 우선순위
        => ++a는 전위 증가 연산자로 a를 증가시키고 증가된 a 값을 표현식의 결과로 사용합니다.
        => a++은 후위 증가 연산자로 증가하지 않은 a 값을 표현식 결과로 사용한 뒤 a를 증가시킵니다.
    
    2-2. 비교 연산자와 논리 연산자
        => 비교 연산자 (>=, <=)는 논리 연산자(&&, ||)보다 우선 순위가 높습니다.
        => && 연산자가 || 연산자보다 우선순위가 높습니다.
