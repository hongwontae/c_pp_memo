1. 논리 연산자
    1-1. 논리 연산자는 하나 이상의 조건식을 평가하여 true | false를 반환하는 연산자입니다.
    1-2. C의 연산 결과는 0 | 1 -> C++은 bool 자료형
    1-3. 논리 연산자는 &&, ||, !이 존재합니다.
    1-4. std :: cout에서 bool 값을 숫자 1 | 0으로 출력합니다.
        => std::cout << std::boolalpha;를 사용해서 문자열 형태로 출력할 수 있습니다.


2. 단락 평가
    => &&는 왼쪽 조건이 false라면 오른쪽 조건은 검사하지 않습니다.
    => 0 && c++ -> c++을 평가하지 않습니다.
    => ||은 왼쪽 조건이 true라면 오른쪽 조건은 검사하지 않습니다.
    => 1 || c++ -> c++을 평가하지 않습니다.


3. 논리 연산자 우선순위
    => ! > && > ||
