1. C++ 참조 변수
    => int a = 10;
    => int& ref = a;

    1-1. int& ref = a; -> ref가 참조변수입니다.
    1-2. int&은 int 타입을 참조하는 자료형, ref는 a에 바인딩 됩니다.
    1-3. ref 값을 변경시 a의 값도 변경됩니다.


2. 참조 변수 메모리 움직임
    => a의 주소-값의 공간을 ref가 가리키는 것입니다.
    => cout << &a << endl; cout << &ref << endl;
    => 같은 주소가 출력됩니다.


3. 참조 변수와 포인터의 차이점
    3-1. 참조 변수는 식별자로 접근하면 바로 값이 나오고 포인터는 역참조 연산자를 사용합니다.
    3-2. 참조 변수는 초기화가 필수적입니다.
    3-3. 다른 객체를 가리키도록 변경할 수 없습니다.
        => 참조 대상의 값을 변경할 수 있습니다.
        => ref = 20; -> 값 변경
        => ref = &b


4. 일반적으로 함수를 호출할 떄 변수나 값을 주면 -> pass by value입니다.
    => 즉, 값이 복사되어 전달됩니다.
    => 함수를 호출하여 caller의 값을 수정하려면 pointer를 사용해야 합니다.
    => pointer의 value는 caller의 변수 주소입니다. -> 그 주소를 역참조하면 caller 변수 값이 도달할 수 있습니다.


5. 참조 변수를 매개변수에 사용한다면?
    => 함수의 매개변수가 참조 자료형을 선언했다면 caller의 변수 자체를 참조하게 됩니다. -> 값 변경 가능
    => 또한 큰 데이터를 복사하지 않고 참조하기에 효율적입니다.


6. const와 참조 변수
    6-1. 참조할 변수가 const라면 참조 변수도 const 키워드를 가져야합니다.
        -> 참조할 변수가 값 변경을 막았기 때문입니다.
    6-2. 참조할 변수가 const가 아니고 참조 변수가 const
        -> 가능합니다.
