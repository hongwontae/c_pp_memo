1. C++ 참조 변수
    => int a = 10;
    => int& ref = a;

    1-1. int& ref = a; -> ref가 참조변수입니다.
    1-2. int&은 int 타입을 참조하는 자료형, ref는 a에 바인딩 됩니다.
    1-3. ref 값을 변경시 a의 값도 변경됩니다.


2. 참조 변수 메모리 움직임
    => a의 주소-값의 공간을 ref가 가리키는 것입니다.
    => cout << &a << endl; cout << &ref << endl;
    => 같은 주소가 출력됩니다.


3. 참조 변수와 포인터의 차이점
    3-1. 참조 변수는 식별자로 접근하면 바로 값이 나오고 포인터는 역참조 연산자를 사용합니다.
    3-2. 참조 변수는 초기화가 필수적입니다.
    3-3. 다른 객체를 가리키도록 변경할 수 없습니다.
