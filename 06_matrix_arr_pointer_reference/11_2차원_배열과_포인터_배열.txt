** []의 우선순위가 *보다 높습니다. 괄호를 사용해서 해석 순서를 바꿀 수 있습니다. **
** 포인터 연산은 포인터가 가리키는 자료형의 크기를 기준으로 이동합니다. **
    => int arr [] = {1,2,3}
    => arr+1 -> 4byte / arr은 int * -> 포인터가 가리키는 자료형은 int -> sizeof(int) -> 4byte

1. 이차원 배열
    => int arr[3][3] = {{1,2,3}, {4,5,6}, {7,8,9}};
    1-1. 각 행의 원소들이 연속적으로 배치된 배열 객체입니다.
    1-2. 중괄호 두 개를 사용해서 초기화할 수 있습니다.
    
    1-3. arr[n]
        => 자료형은 int [n]입니다.
        => 배열 자체를 의미하고 표현식에서 포인터로의 전환이 일어납니다.
        => arr[0] == &arr[0][0], arr[1] == &arr[1][0]

    1-4. arr
        => arr은 자료형은 int (*) [3] 입니다.
        => arr은 (*) 포인터이고 그 포인터가 가리키는 대상은 int [3]개짜리 배열입니다.
        => + 연산시 sizeof(int [3])만큼 이동합니다.
    
    1-5. 표현식 차이
    표현식	        배열 변환 후 또는 표현식 자체의 자료형
    arr_1	        int (*)[3]
    arr_1[0]	    int*
    &arr_1	        int (*)[3][3]
    &arr_1[0][0]	int*


2. 포인터 배열
    int a[] = {1, 2, 3};
    int b[] = {4, 5, 6};
    int c[] = {7, 8, 9};
    int* arr2[3] = {a, b, c};

    2-1. 포인터 배열도 인덱스 접근을 통해 값에 접근할 수 있습니다.
        => cout << arr1[1][2]; // 6
    
    2-2. arr2의 자료형은 int * [3]입니다.
        => [3] int 3개짜리 배열이고 각 배열의 요소는 포인터입니다.

    2-3. arr2에서 *arr2[0] -> 1 / *arr2[1] -> 4 / *arr2[2] -> 7
        => arr2의 3개의 원소들은 1, 4, 7의 주소를 갖고 있습니다.
    
    2-4. 표현식 차이
    표현식	        자료형	    의미
    arr	        int*[3]	    포인터 3개짜리 배열
    arr[0]	    int*	    a의 주소를 저장한 포인터
    *arr[0]	    int	        a의 값 10
    &arr[0]	    int**	    첫 번째 포인터 원소의 주소
    &arr	    int*        (*)[3]	포인터 배열 전체의 주소

    2-5. 포인터 배열 +
        int a = 10;
        int b = 20;
        int c = 30;

        int *arr[3] = {&a, &b, &c};

        => arr[0], arr[1], arr[2]의 값은(address) 연속적임을 보장하지 않습니다.
        => &arr[0], & arr[1], &arr[3]의 주소는 8byte씩 연속적입니다.
