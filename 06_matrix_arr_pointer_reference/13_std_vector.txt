1. std :: vector
    => C++ 표준 라이브러리에서 제공하는 동적 배열(Dynamic Array) 컨테이너입니다.
    => std::vector는 프로그램 실행 도중에도 요소를 추가하거나 제거해서 배열의 크기를 변경할 수 있습니다.


2. C의 arr, std :: array, std :: vector의 차이
    2-1. c 배열, std :: array은 크기 변경이 불가하고 vector는 가능합니다.
    2-2. 요소 저장 위치는 std :: vector는 힙, 나머지는 스택


3. std :: vector는 메모리 할당은 동적으로 수행, 할당과 해제는 스스로 관리합니다.
    => 프로그래머가 new delete를 사용할 필요가 없습니다.


4. 기본 문법
    => std::vector<자료형> 변수명 = {초기회};
    => 요소 개수는 실행 중에 변경할 수 있어, 지정하지 않습니다. 

5. 다양한 초기화 방법
    5-1. 비어 있는 벡터
        => std::vector<int> a;

    5-2. 5개의 요소를 0으로 초기화
        => std::vector<int> b(5);

    5-3. 5개의 요소를 전부 10으로 초기화
        => std::vector<int> c(5, 10);

    5-4. 초기값을 직접 지정
        => std::vector<int> d = {10, 20, 30};  


6. std :: vector 메모리 구조
    => std::vector<int> arr = {10, 20, 30};

    6-1. 요소들이 저장된 메모리의 시작 주소, 현재 사용 중인 요소 영역의 끝, 할당된 전체 메모리 영역의 끝
        => 이 정보를 이용해 요소의 개수, 저장 가능한 용량을 관리합니다.
    6-2. main()의 지역 변수로 선언한 백터 객체는 일반적으로 스택에 존재, 실제 요소들은 동적으로 할당한 힙 영역에 존재합니다.


7. size와 capacity 차이
    7-1. size() : 현재 실제로 존재하는 요소 개수
    7-2. capacity() : 재할당 없이 저장할 수 있는 최대 요소 개수
        => size가 3, capacity가 4 -> 1개를 더 넣을 수 있는 공간이 존재


8. push_back() 호출
    std::vector<int> arr = {10, 20, 30};
    arr.push_back(40);

    8-1. 벡터의 맨 뒤에 새로운 요소를 추가하는 함수입니다.
    8-2. 여유 공간이 존재할 떄 새로운 저장 공간 할당할 필요 없이 그냥 넣으면 됩니다.
    8-3. 여유 공간이 없을 떄
        1. 기존보다 큰 새로운 메모리 공간을 할당한다.
        2. 기존 요소들을 새로운 공간으로 복사하거나 이동한다.
        3. 새로운 요소를 추가한다.
        4. 기존에 사용하던 메모리 공간을 해제한다.
        5. 벡터 객체가 새로운 메모리 공간을 관리하도록 갱신한다.
        => 이 과정이 재할당입니다.
    
    8-4. 재할당이 발생하면 기존 요소를 가리키던 포인터, 참조자, 반복자가 무효화 됩니다.
        => std::vector<int> arr = {10, 20, 30};
        => int* ptr = arr.data();
        => arr.push_back(40); // 재할당이 발생할 수 있음
        => ptr은 재할당이 발생하면 사용하면 안됩니다.


9. std::vector의 주요 멤버 함수
    멤버 함수	            기능
    push_back(value)	마지막에 요소 추가
    pop_back()	        마지막 요소 제거
    size()	            현재 요소 개수
    capacity()	        현재 확보한 저장 용량
    empty()	            비어 있는지 확인
    clear()	            모든 요소 제거
    resize(n)	        요소 개수를 n개로 변경
    reserve(n)	        최소 n개를 저장할 용량 확보
    at(index)	        범위 검사를 하면서 접근
    front()	            첫 번째 요소에 접근
    back()	            마지막 요소에 접근
    data()	            첫 번째 요소를 가리키는 포인터 반환
    insert()	        지정한 위치에 요소 삽입
    erase()	            지정한 위치의 요소 제거


10. vector와 포인터의 관계
    std::vector<int> arr = {10, 20, 30};
    int* ptr = arr.data();

    std::cout << ptr << '\n';
    std::cout << ptr + 1 << '\n';
    std::cout << ptr + 2 << '\n';

    10-1. &arr은 백터 객체 자체의 주소
    10-2. arr.data() -> 첫 번쨰 요소의 주소
    10-3. &arr[0] -> 첫 번쨰 요소의 주소

    10-4. sizeof(vector)
        => 일반적인 64비트 MSVC 릴리스 구성에서는 sizeof(arr)가 24바이트인 경우가 많습니다.
        => 일반적 구현에서 3개의 정보를 관리합니다.
            -> 시작 주소 포인터, 사용 영역 끝 포인터, 할당 영역 끝 포인터


11. 함수에 vector 전달하기

    => 참조 객체를 사용합니다.
