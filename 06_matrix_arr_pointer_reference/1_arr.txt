1. 배열 이름 완벽 정의
    1-1. int arr [] = {1,2}
    1-2. arr은 int 형 원소 두 개를 연속된 메모리 공간에 저장하는 배열 객체 이름, 타입은 int[2]
        => arr은 배열 객체 이름일 뿐입니다.
    1-3. C++에서 배열 타입의 표현식은 대부분의 상황에서 첫 번쨰 원소를 가리키는 포인터로 자동 변환됩니다.
        => 배열에서 포인터로의 변환(Array-to-pointer conversion)이라고 합니다.
        => 예외 상황이 존재합니다. -> 주소 연산자 & 피연산자로 사용되는 경우 / sizeof의 피연산자로 사용되는 경우
        => &arr -> 컴파일러가 arr이 int[2] 타입 배열 인식 -> 컴파일러가 arr이 & 피연산자이므로 배열에서
            포인터로의 변환 x -> & 연산자가 배열 객체의 전체 주소 구함 -> 결과 타입 int (*) [2] -> 주소
    1-4. int * p = arr;
        => arr은 int[2] 타입의 배열을 나타내지만, p에 대입하는 과정에서는 int* 타입의 포인터로 변환됩니다.
        = int* p = &arr[0]; -> 이러한 역할을 합니다.
    
    1-5. arr == &arr
        => arr은 배열에서 포인터로의 전환
        => &arr은 배열에서 포인터로의 전환 x -> 배열 객체 전체 주소 -> int (*) [2] (배열을 가리키는 포인터)
        => [] > *


2. 변수가 아닌 표현식이나 리터럴들은 주소 공간을 가지지 않는 경우가 많습니다.
    => char * p = "hello-world"; -> 이 경우에는 가짐
    => int a = 10 + 20 -> 이 경우에는 없음 -> &10??
    => 이와 마찬가지로 int * p = arr; -> arr이 표현식으로 변환되는 value는 있지만 address는 없음


3. 함수의 매개변수가 int arr [n]으로 기재되어 있을 때 포인터 변수로 변환됩니다.
    => void do_something(int arr[3])
    => void do_something(int* arr) -> 이렇게 취급합니다.
    => 즉, arr_1의 address는 int **, value는 arr_1의 address -> arr_1의 첫 번쨰 원소 주소
    
    => 가장 다른 점은 함수에서 &arr과 main에서 &arr == arr의 값이 다르다는 점입니다.
    => do_something에서 &arr은 int **을 의미하게 되었고 main에서는 첫 번쨰 원소의 주소를 의미합니다.
