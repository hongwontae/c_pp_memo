1. std :: array
    => 고정된 개수의 요소를 저장하는 C++ 표준 라이브러리의 배열 컨테이너입니다.


2. 기본 문법
    => std :: array <자료형, 요소_개수> 변수이름 = {초기화..};
    => 기존 C 배열은 컴파일러가 요소_개수를 적지 않아도 채워넣었지만 std :: array는 컴파일 시점에 결정되어야 합니다.


3. 메모리 구조
    3-1. 요소들이 메모리상에 연속적으로 존재합니다.
    3-2. 일반적인 구현에서는 스택 공간에 존재합니다.


4. std :: array에서 제공하는 기능
    => 일반적인 C 배열은 인덱스 접근 제외 멤버 함수가 없습니다.
    => std :: array는 유용한 멤버 함수가 많습니다.

    기능	            설명
    arr[index]	    해당 인덱스의 요소 접근
    arr.at(index)	범위를 검사하면서 요소 접근
    arr.front()	    첫 번째 요소 접근
    arr.back()	    마지막 요소 접근
    arr.size()	    요소 개수 반환
    arr.empty()	    배열이 비어 있는지 확인
    arr.data()	    첫 번째 요소를 가리키는 포인터 반환
    arr.fill(value)	모든 요소를 특정 값으로 변경
    
    => at 접근은 잘못된 범위로 접근하면 std :: out_of_range 예외가 발생합니다.
    => 일반적인 index 접근은 무분별한 접근을 허용합니다.


5. std :: array 변수는 표현식에서 자동으로 포인터가 되지 않습니다.
    => 배열 객체를 감싸는 클래스 타입입니다.
    => .data()를 통해 포인터로 변환해야 합니다.


6. 일반적인 구현에서는 sizeof(arr) -> arr의 전체 크기만큼 나옵니다. -> int 3개 -> 12


7. std::array를 함수의 매개변수로 전달하면 값을 복사해서 전달하기에 함수에서의 수정은 원본에 영향을 주지 않습니다.
    => 원본을 수정하려면 std :: array <int, 3> & arr -> 참조 변수를 전달합니다.
