1. C의 동적할당
    1-1. malloc
        => int* ptr = malloc(sizeof(int));
        => sizeof(int)만큼 메모리를 확보합니다.
        => 확보한 메모리의 시작 주소를 void* 타입으로 반환합니다.
        => 해당 메모리는 초기화되지 않습니다.
        => 할당이 실패한 경우 NULL 반환됩니다.
    
    1-2. free
        => 할당받은 주소를 인자로 받아서 할당한 공간을 회수합니다.


2. C++의 동적할당
    2-1. new
        => int* ptr = new int;
        => sizeof(int)만큼 메모리를 확보합니다. -> 컴파일러가 int의 크기를 알고 있어 sizeof(int) x
        => 확보한 메모리의 시작 주소를 지정한 타입의 포인터로 반환합니다.
        => 할당이 실패한 경우 std::bad_alloc 예외가 발생합니다.
    
    2-2. new를 사용하면서 초기화하는 방법
        1. int* p1 = new int;
        2. int* p2 = new int(10);
            => 메모리를 할당하고 주소에 해당되는 값에 10를 넣습니다.
            => 메모리 + 값 할당
        3. int* p3 = new int{10};
            => 2와 마찬가지 + 축소 변환 방지
    
    3. new + 배열
        => int* arr = new int[5];
    
    3. delete
        => free()와 같습니다.
        => 배열을 초기화할 떄는 delete [] arr;를 사용해야 합니다. -> [] 필요


3. C/C++에서 사용하는 malloc-free / new-delete는 혼용해서는 안됩니다.
