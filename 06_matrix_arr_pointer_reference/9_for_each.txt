1. 배열 foreach
    => 기존의 for문은 index 변수를 직접 관리하면 배열에 접근합니다.
    => foreach는 인덱스 없이 순차적으로 배열에 접근합니다.
    => foreach를 범위 기반 for문이라고 합니다.


2. 문법
    for (자료형 변수명 : 배열) {
        // 반복할 코드
    }


3. foreach 개념
    3-1. 범위 기반 for문에서 받은 변수는 배열의 각 원소를 복사해서 받습니다.
        => 그렇기에 value = 100; -> 기존 배열에 영향을 주지 못합니다.
    3-2. 참조 변수를 사용한다면 영향을 받습니다.
        => for (int& value : arr) {value = 100;}
        => arr = {100, 100, 100};
    3-3. auto + foreach
        => for (auto& value : arr) {value += 10;}
        => 컴파일러 추론을 이용합니다.
    3-4. C 스타일 배열에는 사용할 수 있지만, 배열이 포인터로 변환된 상태에서는 그대로 사용할 수 없습니다.
        => 포인터에는 배열의 원소 개수 정보가 없기 떄문에 범위 기반 for문이 어디까지 순회해야 하는지 모릅니다.
