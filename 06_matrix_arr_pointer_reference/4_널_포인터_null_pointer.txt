1. C의 NULL
    1-1. C에서 NULL은 C언어의 키워드가 아닙니다.
    1-2. NULL은 표준 라이브러리에서 정의하는 매크로입니다.
        => #define NULL 0 | #define NULL ((void*)0)
        => (void*)0 -> 정수 상수 0을 void * 타입으로 명시적 형변환
    1-3. C언어에서 0 정수 상수 표현식은 널 포인터 상수로 사용할 수 있습니다.
        => int* p = 0;
    1-4. NULL 포인터 값이란?
        => 일반적인 컴퓨터에서는 널 포인터 값이 모든 비트가 0인 경우가 많습니다.
        => 그러나 C 표준은 널 포인터를 특정한 숫자나 비트 패턴으로 정의하지 않습니다.
        => 어떤 유효한 객체나 함수도 가리키지 않는 포인터 값이라는 의미를 정의합니다.


2. C++ nullptr
    2-1. C++에서 정수 0을 널 포인터 상수로 사용하는 방법에 문제가 있습니다.
        void test(int value) {
        cout << "int 함수" << endl;
        }

        void test(int* ptr) {
            cout << "int* 함수" << endl;
        }

        int main() {
            test(0);
            test(NULL);
        }
    
    2-2. NULL이 0 또는 정수형 상수로 정의된 환경에서는 void test (int * ptr)이 실행되지 않습니다.

    2-3. nullptr
        => 널 포인터를 표현하기 위한 특별한 리터럴입니다.
        => std::nullptr_t 타입으로 표현할 수 있습니다.
        => test(nullptr); -> int* 함수
        => 컴파일러는 nullptr이 정수가 아니라 널 포인터를 의미한다는 것을 명확하게 알 수 있습니다.
        => 즉, NULL 대신 nullptr을 사용하는 이유는 정수 0과 구별이 명확 -> 컴파일러 명확히 구분 가능
        => int * p = nullptr일 때 물리적인 주소 값을 0x 0000 0000을 저장한다고 단정지을 수 없습니다.
            -> 환경에 따라 다릅니다.
