1. 2차원 배열
    1-1. int double_arr [3][3] = {{1,2,3}, {4,5,6}, {7,8,9}};
    
    1-2. double_arr
        => type은 int [3][3] -> 이차원 배열 자체를 의미합니다.
        => double_arr은 표현식에서 사용했을 경우 주소로 변환됩니다.
            -> 이 떄 첫 행 첫 열의 주소로 변환됩니다.
        => *(double_arr+1) -> 12만큼 이동합니다. -> row만큼 이동합니다.
    
    1-3. double_arr[n]
        => type은 int [n] -> 행을 의미합니다.
        => double_arr[n]을 표현식에서 사용했을 경우 주소로 변환됩니다.
            -> 이 떄 n행의 첫 열의 주소로 변환됩니다.
        => *(double_arr[n]+1) -> 4만큼 이동합니다. -> int만큼 이동합니다.
    
    1-4. double_arr [n][n]
        => type은 int -> int 형입니다.
        => double_arr[n][n]은 value로 나옵니다.
