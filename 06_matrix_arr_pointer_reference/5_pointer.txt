1. C/C++의 문자열 포인터
    => char * name = "hong" | const char * name = "hong"
    => C에서는 모두 허용됩니다. | C++에서는 const만 허용됩니다.

2. C와 C++에서 문자열 리터럴 -> 문자 배열의 타입은 서로 다릅니다.
    => C는 char [5], C++ const char [5]
    => 그렇기에 C++에서는 const가 붙어야 허용이 됩니다.

3. 그러나 C의 문자열 리터럴이 char [5]일지라도 문자열 리터럴 수정은 정의되지 않은 동작입니다.

4. 문자열을 수정하고 싶다면?
    => char name [5] = "hong";
    => name[0] = 'k';
    => 배열에 문자열 리터럴이 들어간다면 copy by value입니다.
    => 포인터의 경우 첫 번쨰 문자의 주소값이 들어갑니다.


5. cout에서 문자 타입 주소를 받으면 널 문자가 나올 때까지 출력합니다.
    => char name = 'k'
    => cout << &k << endl;
