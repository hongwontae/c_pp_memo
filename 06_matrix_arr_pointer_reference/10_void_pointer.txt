1. void 포인터 (void *)
    1-1. 특정 자료형을 가리키도록 정해져 있지 않은 포인터입니다.
    1-2. 자료형을 가리키는 포인터의 경우 역참조와 포인터 연산이 불가합니다.
        => void 포인터는 역참조가 불가합니다.
        => 주소를 따라가면 2진 데이터를 알 수 있지만 이것을 표현할 자료형을 모르기 때문입니다.
        => 포인터 연산을 하려면 자료형의 크기를 알고 움직여야 하는데 이를 모릅니다.
        => void *를 형변환하여 역참조와 포인터 연산을 할 수 있습니다.
    1-3. void 포인터는 다양한 자료형 주소를 가질 수 있습니다.
        => float, int, char....
    1-4. void *의 사용 이유는 자료형이 서로 다른 객체의 주소를 공통된 방식으로 다루기 위해서입니다.
        => malloc의 반환형은 void * -> 해당 메모리를 어떤 자료형으로 사용할지 모르기 때문입니다.
