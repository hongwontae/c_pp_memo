1. 배열 선택 정렬 알고리즘
    1-1. 배열의 첫 번쨰 요소를 기준으로 삼습니다.
    1-2. 첫 번쨰 요소와 모든 요소를 비교하여 기준에 적합한 인덱스를 찾습니다.
    1-3. 첫 번쨰 요소와 적합한 인덱스가 일치하지 않는다면 인덱스를 통해 교체해줍니다.


2. 배열 버블 정렬 알고리즘
    => 서로 인접한 두 원소를 비교해서 순서가 잘못되어 있다면 교환하는 방식입니다.
    2-1. 총 루프 횟수는 n==5일 떄 4+3+2+1 -> 10 / n == 7이라면 6+5+4+3+2+1 -> 21
    2-2. 서로 인접한 두 원소를 오른쪽으로 옮겨가며 교환하는 방식입니다.
    2-3. 1번 loop을 돌 떄 마지막 원소에는 기준에 적합한 값이 들어있습니다.
    2-4. 이중 for문을 통해서 n이 5일 떄 4번, 3번, 2번, 1번 반복을 만들어줘야 합니다.

    2-5. 코드에서 외부 for은 i는 for 내부의 정렬된 원소에 접근하지 못하는 값이 되어줍니다.
        => int j = 0; j < length - i - 1 ; ++j
        => 0 < 4, 0 < 3, 0 < 2, 0 < 1
        => 0 < 3, 0 < 2, 0 < 1
        => 0 < 2, 0 < 1
        => 0 < 1
