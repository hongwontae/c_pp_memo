1. call by address
    => 함수의 매개변수를 포인터로 선언하고, 원본 변수의 주소를 전달하는 방식입니다.
    => 엄밀하게 말하자면 call by address는 call by value의 일종입니다. -> 주소 값 자체가 복사되어 전달


2. void add(int* ptr) {*ptr += 10;}
    2-1. 주소값을 복사해서 ptr의 value에 넣습니다.
    2-2. 역참조나 인덱스 접근을 통해 원본 변수에 접근할 수 있고 수정할 수 있습니다.
    2-3. const를 앞에 두면 주소를 따라간 값 변경 불가, const를 뒤에 int * 뒤에 두면 주소 변경 불가
        => const를 뒤에 두는 경우는 없습니다. -> 어처피 영향을 주지 못하는 함수 내 지역 변수이기 때문입니다.
