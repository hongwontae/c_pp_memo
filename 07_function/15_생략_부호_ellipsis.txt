2. 생략 부호
    2-1. void print(int count, ...);
        => 첫 번쨰 인수 count는 반드시 int
        => 그 뒤에는 개수가 정해지지 않은 인수들을 전달할 수 있습니다.
        => print(2, 10, 20); print(3, 10, 20, 30); print(4, 10, 20, 30, 40); -> 모두 가능
    
    2-2. 생략 부호로 받은 값 사용하기
        => 생략 부호로 전달된 인수에는 a, b, c처럼 이름이 없습니다.
        => C++에서는 <cstdarg> 헤더에서 제공하는 기능을 사용합니다.

        기능	     역할
        va_list	    가변 인수를 순회하기 위한 상태를 저장하는 타입
        va_start	가변 인수 접근을 시작하도록 초기화
        va_arg	    다음 인수를 지정한 타입으로 가져오기
        va_end	    가변 인수 접근을 종료
    
    2-3. C의 printf가 이러한 생략 부호를 사용합니다.
        => %d, %lld, %s.. 서식 문자열을 통해 인수의 타입을 판단합니다.
        => 서식 지정자와 실제 인수 타입이 일치하지 않으면 정의되지 않은 동작 발생할 수 있습니다.
