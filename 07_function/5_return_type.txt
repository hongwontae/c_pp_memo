1. 일반 자료형 반환 (Return by Value)
    => callee의 지역 변수를 return value로 사용하면 값이 복사되어 전달됩니다.
    => callee의 지역 변수와 값을 받은 caller의 지역 변수는 주소가 다릅니다.


2. 참조 반환 (return by reference)
    2-1. callee의 반환 타입이 참조, 매개 변수가 참조일 떄 caller의 변수가 참조 변수이고
            그 매개변수를 return 했을 떄 callee와 caller의 변수들은 같은 객체를 참조합니다.
    2-2. callee의 반환 타입만 참조라면 위험한 코드입니다.
        => callee의 참조 타입을 전달했지만 callee는 호출이 끝나면 지역 변수들을 정리합니다.
        => 수명이 끝난 객체를 참조하고 이를 댕글링 참조라고 합니다.
    2-3. 참조를 반환한다고 해도 caller에서 참조로 받지 않으면 값 초기화입니다.


3. 주소 반환
    3-1. caller에서 주소를 전달하고 callee에서 주소를 전달하는 구조입니다.
    3-2. 역참조로 caller의 변수에 접근할 수 있습니다.
    3-3. callee에서 주소 변수를 만들어서 return 하는 것은 위험합니다.
        => 수명이 끝난 객체에 접근 -> 댕글링 포인터


4. 구조체 반환
    4-1. 구조체 반환도 return by value입니다.
    4-2. 구조체를 반환할 떄 참조나 포인터를 사용할 수 있습니다.


5. 튜플 반환
    => std :: tuple <int, float> tuple_value () {}
    => 튜플 자체를 반환하거나 튜플 참조를 반환할 수 있습니다.
