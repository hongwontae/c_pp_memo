1. 함수 포인터
    1-1. 함수 이름은 표현식에서 함수 시작 주소를 반환합니다.
    1-2. 함수 호출은 함수의 시작 메모리로 가서 연산을 실행하고 return address로 돌아오는 행위입니다.
    1-3. 함수 또한 메모리에 존재하고 code 영역에 존재합니다.
        => 메모리상의 주소를 가지고 있고 함수 이름은 시작 주소를 반환할 수 있습니다.
    1-4. 함수 포인터는 함수의 주소를 저장하는 포인터입니다.


2. 함수 주소 얻는 방법
    => 함수_이름 || &함수_이름
    => 둘 다 함수 시작 주소를 반환합니다.


3. 함수 포인터 문법
    => 반환_타입 (* 함수_포인터_이름) (매개변수_1, 매개변수_2..) = 함수_주소;
    => 함수_주소는 함수 이름을 사용하면 됩니다.
    => 매개변수는 값으로 받은 함수_주소를 맞춰야 합니다.

3. 함수 포인터로 함수를 호출하는 방법
    => 함수_포인터_이름();
    => (*함수_포인터_이름)();


4. 함수 포인터는 매개변수로 전달될 수 있습니다.
    => void calculate(int a, int b, int (*func)(int, int));
    => 반환_타입 (*함수_포인터_이름) (argument..)
    => 함수 포인터를 사용하면 어떤 작업을 수행할지 호출하는 쪽에서 결정할 수 있습니다.


5. using으로 함수 포인터 선언 간단하게 만들기
    => int (*ptr)(int, int);
    => using FuncPtr = int (*)(int, int);
    => void calculate(int a, int b, FuncPtr func);


6. 함수 포인터는 nullptr을 할당받을 수 있습니다. 
    => 다만 nullptr을 가진 함수 포인터를 호출할 수 없습니다.
