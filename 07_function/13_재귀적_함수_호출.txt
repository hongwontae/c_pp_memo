1. 재귀 함수
    => 함수 내부에서 자기 자신을 다시 호출하는 함수입니다.
    => 함수를 호출할 때마다 새로운 함수 실행이 시작됩니다.
    => 먼저 호출한 함수는 나중에 호출한 함수가 끝날 때까지 기다립니다.


2. 예시
    int factorial(int n) {

        if (n == 1) {
            return 1;
        }

        return n * factorial(n - 1);
    }

    2-1. factorial(5)를 호출합니다.
    2-2. 2-1은 if문을 검사하고 return n * factorial(5-1);를 만납니다.
    2-3. 스택에 factorial(5)는 남아있고 factorial(4)를 호출합니다.
    2-4. 이렇게 스택에 if문을 검사한 factorial(5) ~ factorial(2)까지 존재합니다.
    2-5. factorial(1)이 되는 순간 if문 검사로 return 1이 되면서 factorial(1)은 factorial(2)에게
            1을 주면서 스택에서 제거됩니다.
    2-6. factorial(2)는 return 2 * 1이 되면서 factorial(3)에게 2를 전달합니다.
    2-7. factorial(3)은 return 3 * 2가 되면서 factorial(4)에게 6을 전달합니다.
    2-8. factorial(4)는 return 4 * 6이 되면서 factorial(5)에게 24를 전달합니다.
    2-9. factorial(5)는 return 5 * 24가 되고 자신 아래의 main에게 값을 전달합니다.
        => 120
