1. std :: tuple
    => 서로 다른 자료형의 데이터 여러 개를 하나의 객체로 묶어서 관리할 수 있는 표준 라이브러리 타입입니다.
    => 함수에서 여러 값을 한 번에 반환할 떄 유용합니다.


2. 튜플 내부 구조
    => std::tuple<int, double, char> person{25, 175.5, 'A'};
    2-1. 각 요소는 서로 다른 자료형을 가질 수 있습니다.
    2-2. 요소의 개수와 타입은 컴파일 시점에 결정됩니다.
    2-3. 인덱스는 0부터 시작합니다.
    2-4. 배열처럼 런타임에 요소를 추가하거나 제거할 수 없습니다.


3. 튜플 선언과 초기화
    3-1. #include <tuple> 헤더로 사용할 수 있습니다.
    3-2. 직접 타입 지정
        => std::tuple<int, double, char> t1{10, 3.14, 'A'};
    
    3-3. std::make_tuple() 사용
        => auto t2 = std::make_tuple(10, 3.14, 'A');
        => 컴파일러가 타입을 추론합니다.
    
    3-4. std::tuple t3{10, 3.14, 'A'};
        => C++ 17부터 사용가능합니다.
        => 컴파일러가 요소들의 타입을 추론합니다.


4. 튜플 요소에 접근하는 방법
    4-1. std :: get<n>(튜플명);
        => <> -> 인덱스 / 인덱스는 컴파일 타입에 결정되어야 합니다. -> 리터럴을 받아야 함
        => () -> 튜플 객체


5. 튜플 요소 수정
    std::get<0>(data) = 100;
    std::get<1>(data) = 6.28;
    std::get<2>(data) = 'B';

    int& ref = std::get<0>(data);


6. 튜플 구조적 바인딩
    => std::tuple<int, double, char> data{10, 3.14, 'A'};
    => auto [a, b, c] = data;
    => a는 10, b는 3.14, c는 'A'
    
    6-1. auto [a, b, c] = data;
        => a, b, c라는 값을 복사해서 int a, float b, char c를 사용하는 것과 같습니다.
    
    6-2. auto& [a, b] = data;
        => 기존의 튜플 객체의 참조입니다. 값을 수정하면 기존 튜플 객체도 변경됩니다.
