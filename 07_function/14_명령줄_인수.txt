1. 명령줄 인수
    => 프로그램을 실행할 떄 프로그램에 전달하는 값을 의미합니다.


2. main() 함수도 매개변수를 받을 수 있습니다.
    int main(int argc, char* argv[]) {
        return 0;
    }

    => argc : 인수의 개수
    => argv : 인수 문자열들을 가리키는 포인터의 배열 char * []


3. C:\Users\Hong> program.exe hello 123
    => program.exe를 실행
    => 프로그램이 실행된 경로 (첫 번쨰 명령줄 인수)
    => hello (두 번쨰 명령줄 인수)
    => 123 (세 번쨰 명령줄 인수)
    => 프로그램을 실행하면서 외부에서 데이터를 전달하는 방법이 명령줄 인수입니다.
    => argc는 3, argv는 "program.ext", "hello", "123"
