1. 매개변수 기본값
    => 함수를 정의할 때 매개변수에 기본값(Default Argument) 을 지정할 수 있습니다.
    => 함수를 호출할 때 특정 인자를 전달하지 않아도, 컴파일러가 미리 지정된 기본값을 사용하도록 처리합니다.


2. 매개변수 기본값은 여러 매개변수에 지정할 수 있습니다.
    => C++에서 기본적으로 앞쪽 매개변수부터 인자를 전달하고, 뒤쪽 매개변수의 인자만 생략할 수 있습니다.


3. 기본값은 오른쪽 매개변수부터 지정해야 합니다.
    => void func(int a = 10, int b) {} -> 컴파일 오류 발생
    =>void func(int a, int b = 20, int c); -> 컴파일 오류 발생
    => void func(int a, int b = 20) {} -> 컴파일 성공
    => void func(int a = 10, int b = 20) {} -> 컴파일 성공

    => 즉, 기본값을 가진 매개변수의 오른쪽에 기본값이 없는 매개변수를 남겨둘 수 없는 규칙이 있습니다.


4. 함수 선언과 정의가 분리되어 있을 떄 선언과 정의 둘 다 매개변수 기본값이 있으면 컴파일 에러가 발생합니다.
    => 일반적으로 헤더 파일에 기본값을 작성합니다.
    => 기본 인자가 함수 호출을 컴파일할 떄 사용되기 떄문입니다.


5. 기본값은 컴파일 타임에 처리됩니다.
    => 호출하는 시점에 생략된 인자를 기본 인자 표현식으로 보충합니다.
    => add(20); -> 컴파일러가 함수를 살펴본 후 -> add(20, 10)


6. 함수 오버로딩과 매개변수 기본값
    #include <iostream>
    using namespace std;

    void print(int a) {
        cout << "첫 번째 함수" << endl;
    }

    void print(int a, int b = 20) {
        cout << "두 번째 함수" << endl;
    }

    int main() {
        print(10);

        return 0;
    }

    6-1. print(10);
        => 컴파일 오류가 발생합니다.
        => 컴파일러가 선택할 수 있는 함수가 두 개이기 때문입니다.
